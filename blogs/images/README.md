# Blog images

Place landscape WebP images in this folder. The blog engine uses only this directory, so it remains independent from global website assets.

- Size: 1200 × 675 px (16:9)
- Format: WebP
- File name: destination slug, for example `udaipur.webp`, `jaipur.webp`, `jaisalmer.webp`
- Keep images free of text and logos; use descriptive real-destination photography.

The 1000 articles reuse 40 destination images. Missing images are hidden gracefully until uploaded.
