# Swiggy Wala logo assets

Use SVG files whenever the platform supports them. PNG exports are provided for platforms that require raster images.

| File | Ratio / size | Recommended use |
| --- | --- | --- |
| `logo-mark.svg` | 1:1 vector | Master icon, app icon, favicon source |
| `logo-horizontal.svg` | 60:13 vector | Website header, documents, light backgrounds |
| `logo-horizontal-white.svg` | 60:13 vector | Footer and dark backgrounds |
| `logo-wide.svg` | 3:1 vector | Wide brand banner |
| `logo-mark-1024.png` | 1024×1024 | High-resolution square logo |
| `icon-512.png` | 512×512 | App/profile icon |
| `icon-192.png` | 192×192 | PWA and mobile icon |
| `favicon-64.png` | 64×64 | Browser/favicon fallback |
| `favicon-32.png` | 32×32 | Browser favicon |
| `logo-horizontal-1600.png` | 1600×347 | HD horizontal logo |
| `logo-horizontal-800.png` | 800×173 | Standard horizontal logo |
| `logo-horizontal-white-800.png` | 800×173 | White horizontal logo |
| `logo-wide-1500x500.png` | 1500×500 | Wide listing/banner logo |

Do not stretch the logo. Keep clear space equal to at least one quarter of the bird mark’s width.
